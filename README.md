# Chúc mừng 20/10 · Lớp 11A6

Website chúc mừng 20/10 dành cho các bạn nữ lớp 11A6. Trang có giao diện hoa rơi, thiệp lời chúc và 50 câu chúc được viết trực tiếp trong file `index.html`.

## Đưa website lên GitHub Pages

1. Mở repository `yvhgh2473-max/20-10v` trên GitHub.
2. Chọn **Add file → Upload files**.
3. Tải `index.html` và `README.md` từ thư mục này lên **thư mục gốc** của repository. Sau khi chọn file, GitHub phải hiển thị `index.html` ở cấp đầu tiên, không nằm trong thư mục con.
4. Chọn **Commit directly to the `main` branch** rồi nhấn **Commit changes**.
5. Mở **Settings → Pages**. Trong **Build and deployment**, chọn **Deploy from a branch**, chọn nhánh `main` và thư mục `/(root)`, rồi nhấn **Save**.
6. Đợi GitHub Pages hoàn tất xuất bản rồi mở:

   <https://yvhgh2473-max.github.io/20-10v/>

`index.html` là file chạy website. `README.md` chỉ là hướng dẫn. Không cần cài thư viện, tải thêm ảnh, build hoặc thêm backend.

## Lời chúc riêng

Mỗi tên nhận một câu trong 50 lời chúc có sẵn. Trên **cùng trình duyệt và thiết bị**, nhập lại một tên sẽ nhận đúng câu cũ; tên mới nhận một câu chưa được dùng. Khi cả lớp chia sẻ một thiết bị, hãy lần lượt nhập tên trên chính trình duyệt đó.

Danh sách tên đã nhận được lưu trong bộ nhớ của trình duyệt, không gửi lên máy chủ. Nếu các bạn mở website trên nhiều điện thoại hoặc trình duyệt khác nhau, mỗi thiết bị có danh sách riêng nên không thể bảo đảm tránh trùng giữa các thiết bị.
