# Chúc mừng 20/10 · 11A6

Trang web gửi lời chúc riêng đến các bạn nữ lớp 11A6, kèm bó hoa hoạt hình, cánh hoa rơi và hiệu ứng tặng hoa.

## Xem trang web

GitHub Pages được triển khai tự động từ nhánh `main` sau mỗi lần cập nhật.

## 50 lời chúc riêng

Mỗi trình duyệt lần lượt dành một câu khác nhau trong danh sách 50 câu cho mỗi tên. Nhập lại cùng tên sẽ nhận lại câu cũ. Dữ liệu tên và số câu được lưu trên trình duyệt, không gửi lên máy chủ. Để cả lớp dùng chung danh sách, các bạn cần lần lượt nhận lời chúc trên cùng một trình duyệt/thiết bị.
